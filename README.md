# Occult Archive

## About the Project
* Details the extracurricular, academic, and personal life's of 4 occult club members — Harvey, Elliot, Milo, and Casey
* Serves as more out of game information for a visual novel in development
* Currently includes occult club information and the layout for Milo's webpage

## Deployment:
* In order to access the webpage, click on the following demo link|: https://silvendz.github.io/thirdspacegame/

## Features:
* A built-in navigation bar that allows the user to navigate across different pages, including the occult club's webpage and the member's personal websites.
* Contains images such as flyers made by myself in order to create a realistic experience
* UI personalized for each character in order to portray their personalities and role
